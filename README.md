# shild-IDS
A custom-built Security Intrusion Detection System (SIDS) designed to protect institutional web assets. The tool monitors network traffic in real-time to identify and block malicious exploitation attempts, such as SQL Injection and Arbitrary File Read vulnerabilities. It features automated incident logging and defensive response mechanisms to ensure the integrity and resilience of web infrastructure against cyber threats
